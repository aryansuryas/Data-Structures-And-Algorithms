

🔢 FizzBuzz

📝 Problem Statement
Given an integer n, return a string array containing the numbers from 1 to n.

Rules

| Condition                  | Output     |
|----------------------------|------------|
| Divisible by 3 and 5   | "FizzBuzz" |
| Divisible by 3           | "Fizz"     |
| Divisible by 5           | "Buzz"     |
| Otherwise                  | Number itself |

---

📊 Example

Input
`
n = 15
`

Output
`
["1","2","Fizz","4","Buzz","Fizz","7","8","Fizz","Buzz","11","Fizz","13","14","FizzBuzz"]
`

---

💡 Approach
1. Loop from 1 to n.
2. Check if the number is divisible by both 3 and 5.
3. Otherwise check divisibility by 3.
4. Otherwise check divisibility by 5.
5. If none match, convert the number to a string.
6. Store the result in the answer vector.

---
`
💻 C++ Solution
`cpp
class Solution {
public:
    vector<string> fizzBuzz(int n) {
        vector<string> ans;

        for (int i = 1; i <= n; i++) {
            if (i % 3 == 0 && i % 5 == 0) {
                ans.push_back("FizzBuzz");
            }
            else if (i % 3 == 0) {
                ans.push_back("Fizz");
            }
            else if (i % 5 == 0) {
                ans.push_back("Buzz");
            }
            else {
                ans.pushback(tostring(i));
            }
        }

        return ans;
    }
};
