FizzBuzz

Simple C++ solution for the FizzBuzz problem.

Problem

Given an integer "n", return numbers from "1" to "n" with these rules:

- Divisible by "3" → "Fizz"
- Divisible by "5" → "Buzz"
- Divisible by both "3" and "5" → "FizzBuzz"
- Otherwise → number itself

Example

Input:

n = 15

Output:

1 2 Fizz 4 Buzz Fizz 7 8 Fizz Buzz 11 Fizz 13 14 FizzBuzz

Approach

1. Loop from "1" to "n".
2. Check divisibility by both "3" and "5".
3. Check divisibility by "3".
4. Check divisibility by "5".
5. Otherwise, add the number as a string.

Code

class Solution {
public:
    vector<string> fizzBuzz(int n) {
        vector<string> ans;

        for (int i = 1; i <= n; i++) {

            if (i % 3 == 0 && i % 5 == 0) {
                ans.push_back("FizzBuzz");
            }
            else if (i % 3 == 0) {
                ans.push_back("Fizz");
            }
            else if (i % 5 == 0) {
                ans.push_back("Buzz");
            }
            else {
                ans.push_back(to_string(i));
            }
        }

        return ans;
    }
};

Complexity

- Time: "O(n)"
- Space: "O(n)"
