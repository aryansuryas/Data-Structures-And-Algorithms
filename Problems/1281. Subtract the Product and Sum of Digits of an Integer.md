# LeetCode 1281: Subtract the Product and Sum of Digits of an Integer

## 🎯 Goal
The function calculates the difference between the product and the sum of the individual digits of a given positive integer `n`. It uses **digit extraction via modulo arithmetic** inside a `while` loop to process each digit sequentially.

## 🛠️ Code Implementation
```cpp
#include <iostream>

using namespace std;

class Solution {
public:
    int subtractProductAndSum(int n) {
        int prod = 1; // Initialized to 1 since multiplying by 0 would ruin the product
        int sum = 0;  // Initialized to 0 as the identity element for addition
        
        while (n != 0) {
            int digit = n % 10; // Extract the last digit of the number
            prod = prod * digit; // Multiply the running product by the current digit
            sum = sum + digit;   // Add the current digit to the running sum
            n = n / 10;          // Remove the last digit from the number
        }

        return prod - sum; // Return the final calculated difference
    }
};
```

## 🔄 Trace Example (n = 234)

| Step | Current `n` | Extracted `digit` | Running `prod` (Calculation) | Running `sum` (Calculation) | Remaining `n` |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 234 | 4 | 4 (1 * 4) | 4 (0 + 4) | 23 |
| 2 | 23 | 3 | 12 (4 * 3) | 7 (4 + 3) | 2 |
| 3 | 2 | 2 | 24 (12 * 2) | 9 (7 + 2) | 0 |

**Result:** `15` (Since `24 - 9 = 15`)

## ⚠️ Edge Cases Handled
* **Single Digit Inputs (e.g., \(n = 5\)):** The loop runs exactly once. `prod` becomes 5, `sum` becomes 5, and the function safely returns `5 - 5 = 0`.
* **Digits Containing Zero (e.g., \(n = 102\)):** As soon as the zero digit is extracted, the running `prod` becomes `0` and stays `0` for the remaining iterations, which is mathematically correct.

## 💡 Key Takeaways
* **Base-10 Operations:** Modulo 10 (`% 10`) always extracts the rightmost digit of a number, while integer division by 10 (`/ 10`) shifts the number right by one decimal place.
* **Identity Value Initialization:** Always ensure accumulator variables are initialized correctly based on their operation: `0` for addition counters and `1` for multiplication counters.

## ⚡ Complexity Analysis
* **Time Complexity:** \(O(\log_{10} n)\)
  * The number of iterations is strictly determined by the number of digits in `n`. For any integer \(n\), it has \(\lfloor\log_{10} n\rfloor + 1\) digits.
* **Space Complexity:** \(O(1)\)
  * The algorithm computes the result in place using a few primitive integer properties, consuming constant extra memory.
