# LeetCode 35: Search Insert Position

## 🎯 Goal
This function finds the index where a target value should be inserted into a sorted array to maintain order, returning the exact index if found. It achieves an efficient lookup using the **Binary Search** technique.

## 🛠️ Code Implementation
```cpp
class Solution {
public:
    int searchInsert(vector<int>& arr, int target) {
        int low = 0;
        int high = arr.size() - 1;
        int ans = arr.size(); // Default fallback to the end of the array

        while (low <= high) {
            // Prevents integer overflow compared to (low + high) / 2
            int mid = low + (high - low) / 2;

            if (arr[mid] == target) {
                return mid; // Target found, return index immediately
            } else if (arr[mid] > target) {
                high = mid - 1; // Target is smaller, discard the right half
            } else {
                low = mid + 1; // Target is larger, discard the left half
            }
        }
        return low; // If not found, 'low' points to the correct insertion index
    }
};
```

## 🔄 Trace Example (`arr = [1, 3, 5, 6]`, `target = 5`)

| Step | low | high | mid | arr[mid] | Condition | Action |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | 0 | 3 | 1 | 3 | `3 < 5` | `low = mid + 1` (2) |
| **2** | 2 | 3 | 2 | 5 | `5 == 5` | Return `mid` (2) |

**Result:** The target value `5` is found at index **2**.

## 🔄 Trace Example (`arr = [1, 3, 5, 6]`, `target = 2`)

| Step | low | high | mid | arr[mid] | Condition | Action |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | 0 | 3 | 1 | 3 | `3 > 2` | `high = mid - 1` (0) |
| **2** | 0 | 0 | 0 | 1 | `1 < 2` | `low = mid + 1` (1) |
| **Loop End** | 1 | 0 | - | - | `low > high` | Break loop, return `low` (1) |

**Result:** The target `2` is missing and must be inserted at index **1**.

## ⚠️ Edge Cases Handled
* **Target Smaller Than All Elements**: The `high` pointer reduces to `-1`, loop ends, and `low` remains `0` (correct insertion point).
* **Target Larger Than All Elements**: The `low` pointer increments past the last element to equal `arr.size()`, pointing to the end of the array.
* **Single Element Array**: The loop executes exactly once to check the solitary element and correctly shifts boundaries.
* **Integer Overflow**: Finding `mid` via `low + (high - low) / 2` avoids numerical crashes on massive array boundaries.

## 💡 Key Takeaways
* **Overflow Prevention**: Writing `low + (high - low) / 2` ensures values stay within bounds when `low` and `high` are close to `INT_MAX`.
* **The Invariant Rule**: When the loop terminates without finding the target, the `low` pointer always tracks the exact insertion position.
* **Inclusive Search**: Using `low <= high` ensures that single-element search spaces are thoroughly evaluated before exiting.

## ⚡ Complexity Analysis
* **Time Complexity:** **$\mathcal{O}(\log N)$** because the search space is divided in half during every iteration.
* **Space Complexity:** **$\mathcal{O}(1)$** since the algorithm operates entirely in-place with a fixed number of pointer variables.
