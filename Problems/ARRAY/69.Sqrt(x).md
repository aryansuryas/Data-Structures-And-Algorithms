# LeetCode 69: Sqrt(x)

## 🎯 Goal
Return the truncated integer square root of a non-negative integer `n` using efficient **Binary Search** within the range `[1, n]`.

## 🛠️ Code Implementation

```cpp
class Solution {
public:
    int mySqrt(int n) {
        if (n <= 0) return 0;
        if (n < 2 && n > 0) return n;
        
        int lo = 1, hi = n;
        int res = 1;
        
        while (lo <= hi) {
            long long mid = lo + (hi - lo) / 2; 
            
            if (mid * mid <= n) {
                res = mid;     
                lo = mid + 1;  
            } else {
                hi = mid - 1;  
            }
        }
        return res;
    }
};
```

## 🔄 Trace Example (`n = 8`)

| Step | `lo` | `hi` | `mid` | `mid * mid` | Condition (`<= 8`) | Action | `res` |
| :---: | :---: | :---: | :---: | :---: | :---: | :--- | :---: |
| Start | `1` | `8` | - | - | - | Initial State | `1` |
| 1 | `1` | `8` | `4` | `16` | ❌ No | `hi = 4 - 1 = 3` | `1` |
| 2 | `1` | `3` | `2` | `4` |  Yes | `res = 2`, `lo = 2 + 1 = 3` | `2` |
| 3 | `3` | `3` | `3` | `9` | ❌ No | `hi = 3 - 1 = 2` | `2` |

**Result:** Returns `res = 2` (loop terminates because `lo > hi`).

## ⚡ Complexity Analysis
*   **Time Complexity:** **$O(\log N)$** — Search space is halved each step.
*   **Space Complexity:** **$O(1)$** — Constant auxiliary memory.
