# LeetCode 27: Remove Element

## 🎯 Goal
Remove all occurrences of a target value `val` from an array `nums` **in-place** and return the new length `k`. The first `k` elements must contain the modified array without `val`.

---

## 💡 Core Logic (Two-Pointer Technique)
Instead of deleting items and shifting the array (which is slow), use a **write pointer (`k`)** and a **read pointer (`i`)**:
1. Iterate through the array using `i`.
2. If `nums[i]` is **not** the unwanted value, overwrite `nums[k]` with `nums[i]` and move `k` forward.
3. If `nums[i]` **is** the unwanted value, ignore it and keep moving `i`.

---

## 🛠️ Code Implementation

```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int k = 0; // Write pointer (tracks valid elements)
        
        for (int i = 0; i < nums.size(); i++) { // Read pointer
            if (nums[i] != val) {
                nums[k] = nums[i]; // Overwrite valid element
                k++;               // Move write pointer
            }
        }
        return k; // New length of filtered array
    }
};
```

---

## 🔄 Trace Example
**Input:** `nums = [3, 2, 2, 3]`, `val = 3`

| Step | `i` | `nums[i]` | Condition (`!= 3`) | Action | Array State | `k` |
| :---: | :---: | :---: | :---: | :--- | :--- | :---: |
| Start | - | - | - | Initial State | `[3, 2, 2, 3]` | `0` |
| 1 | `0` | `3` | ❌ No | Skip | `[3, 2, 2, 3]` | `0` |
| 2 | `1` | `2` |  Yes | `nums[0] = nums[1]` | `[2, 2, 2, 3]` | `1` |
| 3 | `2` | `2` |  Yes | `nums[1] = nums[2]` | `[2, 2, 2, 3]` | `2` |
| 4 | `3` | `3` | ❌ No | Skip | `[2, 2, 2, 3]` | `2` |

**Result:** Returns `k = 2`. First 2 elements are `[2, 2]`.

---

## ⚡ Complexity Analysis
*   **Time Complexity:** **$O(N)$** — Single pass through the array.
*   **Space Complexity:** **$O(1)$** — Done in-place without extra memory.
