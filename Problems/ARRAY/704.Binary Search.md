# LeetCode 704: Binary Search

## 🎯 Goal
Find a specified `target` value within a sorted integer array `arr` using **Binary Search**. Return its index if found, or `-1` if it does not exist.

## 🛠️ Code Implementation

```cpp
class Solution {
public:
    int search(vector<int>& arr, int target) {
        int l = 0;
        int r = arr.size() - 1;
        
        while (l <= r) {
            int mid = l + (r - l) / 2; // Prevents potential integer overflow
            
            if (arr[mid] == target) {
                return mid; // Target found
            } else if (arr[mid] > target) {
                r = mid - 1; // Target is in the left half
            } else {
                l = mid + 1; // Target is in the right half
            }
        }
        return -1; // Target not found
    }
};
```

## 🔄 Trace Example (`arr = [-1, 0, 3, 5, 9, 12]`, `target = 9`)

| Step | `l` | `r` | `mid` | `arr[mid]` | Condition (`== 9`) | Action | Result |
| :---: | :---: | :---: | :---: | :---: | :---: | :--- | :---: |
| Start | `0` | `5` | - | - | - | Initial State | None |
| 1 | `0` | `5` | `2` | `3` | ❌ `3 < 9` | `l = 2 + 1 = 3` | None |
| 2 | `3` | `5` | `4` | `9` |  `9 == 9` | Return index `4` | `4` |

**Result:** Returns `4` (Target found at index 4).

## ⚠️ Edge Cases Handled
*   **Target Missing:** Loop finishes (`l > r`) without matching, safely returning `-1`.
*   **Single-Element Array:** Works flawlessly because `l <= r` executes when `l == r`.
*   **Target at Boundaries:** Finds the target instantly if it is the first or last element.
*   **Large Index Boundaries:** Calculation of `mid` avoids arithmetic overflow limits.

## 💡 Key Takeaways
*   **Overflow Prevention:** Using `l + (r - l) / 2` instead of `(l + r) / 2` stops integer overflow.
*   **Inclusive Boundary Check:** The `l <= r` condition ensures every valid element is checked.
*   **Strict Search Reduction:** Shifting pointers to `mid ± 1` guarantees the algorithm terminates.

## ⚡ Complexity Analysis
*   **Time Complexity:** **O(log N)** — The array size is divided by two at each comparison step.
*   **Space Complexity:** **O(1)** — Iterative approach uses only a few pointers, requiring zero extra memory.
