🔍 LeetCode 704 — Binary Search

📌 Problem Number

704. Binary Search

---

📝 Problem Statement

Given a sorted array of integers "arr" and an integer "target", return the index of "target" if it exists in the array.

If the target does not exist, return:

-1

---

🧠 Problem Understanding

Since the array is already sorted, we can use Binary Search instead of checking every element one by one.

Binary Search works by:

Find Middle
     ↓
Compare with Target
     ↓
Go Left OR Go Right
     ↓
Repeat until Found

Example

arr = [1, 3, 5, 7, 9]
target = 7

Middle = 5

7 > 5 → Search Right

Middle = 7

Target Found → Return Index 3

---

💡 Solution Idea

Use two pointers:

Variable| Meaning
"l"| Left boundary of the search space
"r"| Right boundary of the search space
"mid"| Middle index

Keep checking the middle element:

Condition| Action
"arr[mid] == target"| Target found → Return "mid"
"arr[mid] > target"| Target is on the left → "r = mid - 1"
"arr[mid] < target"| Target is on the right → "l = mid + 1"

---

💻 C++ Code

class Solution {
public:
    int search(vector<int>& arr, int target) {
        
        int l = 0;
        int r = arr.size() - 1;
        
        while (l <= r) {
            
            int mid = l + (r - l) / 2;
            
            if (arr[mid] == target) {
                return mid;
            } 
            else if (arr[mid] > target) {
                r = mid - 1;
            } 
            else {
                l = mid + 1;
            }
        }
        
        return -1;
    }
};

---

🔎 Step-by-Step Code Explanation

Step| Code| What It Does
1️⃣| "int l = 0;"| Start searching from the first index
2️⃣| "int r = arr.size() - 1;"| Set the right boundary to the last index
3️⃣| "while (l <= r)"| Continue while there is a valid search space
4️⃣| "int mid = l + (r - l) / 2;"| Find the middle index
5️⃣| "arr[mid] == target"| Target found → Return its index
6️⃣| "arr[mid] > target"| Target is smaller → Search left half
7️⃣| "r = mid - 1"| Remove the middle and right half
8️⃣| "arr[mid] < target"| Target is greater → Search right half
9️⃣| "l = mid + 1"| Remove the middle and left half
🔟| "return -1"| Target does not exist in the array

---

🧪 Dry Run

Input

arr = [1, 3, 5, 7, 9]
target = 7

Step| "l"| "r"| "mid"| "arr[mid]"| Comparison| Action
1| 0| 4| 2| 5| "7 > 5"| Search Right → "l = 3"
2| 3| 4| 3| 7| "7 == 7"| Return "3"

Output

3

⏱️ Time Complexity

"O(log n)"

In every step, Binary Search removes half of the search space.

n
↓
n / 2
↓
n / 4
↓
n / 8
↓
...

Therefore:

Time Complexity = O(log n)

---

💾 Space Complexity

"O(1)"

We only use a few variables:

l
r
mid

No extra array or data structure is created.

Therefore:

Space Complexity = O(1)
